# Run the plan

Read the tasks in the plan. To change one, tell the planner what to change,
or edit the task's runner, model or mode on its card.

Click **Execute Plan** to start the run: running the plan is how you approve it. In a git
repository each task works in its own git worktree, and its result is checked
before it counts. When the run ends, review the combined diff, then merge it
or discard it.
