# Open the Ordewell view

Click the Ordewell icon in the activity bar, or run **Ordewell: Focus Chat**
from the Command Palette.

With a coding agent such as Claude Code or Codex installed and signed in,
Ordewell plans and runs with it: no API key and no setup. With none installed,
the view says how to install one, or how to plan with an API key instead.
